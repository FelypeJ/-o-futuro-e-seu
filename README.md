# O Futuro é Seu 🤖

> Uma experiência narrativa interativa sobre inteligência artificial, escolhas, ética e responsabilidade.

**O Futuro é Seu** é um jogo desenvolvido como atividade de aprendizagem de JavaScript. O jogador acompanha Íris, uma inteligência artificial que passa a participar de decisões importantes para a sociedade. Ao longo de sete situações, cada escolha influencia a narrativa e ajuda a construir um desfecho.

## 🎮 Como jogar

1. Abra o projeto pelo GitHub Pages ou execute localmente.
2. Clique em **Iniciar experiência**.
3. Leia cada situação e selecione uma das três alternativas.
4. Veja a consequência da decisão antes de avançar.
5. Ao final, descubra o desfecho, consulte o resumo das suas tendências e releia suas escolhas.
6. Compartilhe o resultado ou jogue novamente para experimentar outro caminho.

Não existe uma resposta perfeita. A proposta é refletir sobre benefícios, riscos e responsabilidades no uso da inteligência artificial.

## ✨ Funcionalidades

- Interface responsiva para celular e computador.
- Identidade visual futurista com animações leves em CSS e ilustração vetorial SVG.
- Sete situações narrativas com três alternativas cada.
- Tela de consequência entre as decisões, tornando o impacto das escolhas visível.
- Sistema de pontuação com cinco dimensões: confiança, inovação, segurança, autonomia humana e dependência.
- Desfechos diferentes conforme o conjunto de decisões.
- Painel final com leitura das tendências e mensagem de reflexão.
- Histórico completo das escolhas e consequências.
- Compartilhamento nativo quando disponível e alternativa de cópia em navegadores compatíveis.
- Suporte a navegação por teclado e preferência por movimento reduzido.

## 🧰 Tecnologias

- **HTML5** para a estrutura e organização das telas.
- **CSS3** para layout responsivo, identidade visual, animações e acessibilidade.
- **JavaScript** para narrativa, eventos, pontuação, consequências e finais.
- **SVG** para a ilustração vetorial da personagem Íris.

O projeto não utiliza bibliotecas ou frameworks JavaScript. As fontes são carregadas do Google Fonts; sem conexão, o navegador utiliza fontes alternativas.

## ▶️ Como executar localmente

Não é necessário instalar dependências.

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Clique em **Iniciar experiência**.

## 📁 Estrutura de arquivos

```text
o-futuro-e-seu/
├── index.html   # Estrutura das telas e conteúdo
├── style.css    # Identidade visual, responsividade e animações
├── script.js    # Narrativa, escolhas, pontuação e finais
└── README.md    # Documentação do projeto
```

## 📚 Conceitos de JavaScript praticados

- Variáveis e constantes.
- Arrays e objetos.
- Funções e parâmetros.
- Condicionais (`if` / `else`).
- Laços e métodos de arrays.
- Eventos de clique (`addEventListener`).
- Manipulação do DOM (`createElement`, `textContent`, `replaceChildren`).
- `Math.random()` e `Math.floor()` para selecionar consequências.
- Atualização dinâmica de elementos HTML.
- Uso de APIs do navegador para compartilhamento e cópia de texto.

## 🎯 Objetivo educacional

Estimular o pensamento crítico sobre a relação entre pessoas e inteligência artificial, mostrando que decisões tecnológicas envolvem eficiência, privacidade, segurança, autonomia, transparência e responsabilidade coletiva.
