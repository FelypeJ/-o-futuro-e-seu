# O Futuro é Seu 🤖

> Uma experiência narrativa interativa sobre inteligência artificial, escolhas e o futuro da humanidade.

**O Futuro é Seu** é um jogo desenvolvido como atividade de aprendizagem de JavaScript. Durante a experiência, o jogador conversa simbolicamente com uma inteligência artificial chamada Íris e toma decisões que influenciam o rumo da narrativa e o desfecho.

## 🎮 Como jogar

1. Abra o jogo pelo GitHub Pages ou execute localmente.
2. Clique em **Iniciar experiência**.
3. Leia cada situação e escolha uma das alternativas.
4. Acompanhe as consequências das decisões.
5. Ao final, descubra qual futuro suas escolhas ajudaram a construir.
6. Use **Jogar novamente** para experimentar outro caminho.

Não existe uma resposta perfeita: a proposta é refletir sobre benefícios, riscos e responsabilidades no uso da inteligência artificial.

## ✨ Funcionalidades

- Tela inicial e navegação entre etapas.
- Sete situações narrativas com três alternativas cada.
- Consequências e frases selecionadas aleatoriamente.
- Sistema de pontuação que considera confiança, progresso, segurança, autonomia e dependência.
- Desfechos diferentes conforme o conjunto de decisões.
- Registro das escolhas realizadas.
- Opção para copiar o resultado.
- Layout responsivo para celular e computador.

## 🧰 Tecnologias

- **HTML5** para a estrutura.
- **CSS3** para o visual responsivo, animações e acessibilidade.
- **JavaScript** para perguntas, eventos, escolhas, pontuação e finais.

O projeto não utiliza bibliotecas ou frameworks JavaScript. As fontes visuais são carregadas do Google Fonts; sem conexão, o navegador utiliza fontes alternativas.

## ▶️ Como executar localmente

Não é necessário instalar dependências.

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Comece a jogar.

## 📁 Estrutura de arquivos

```text
o-futuro-e-seu/
```

## 📚 Conceitos de JavaScript praticados

- Variáveis e constantes.
- Arrays e objetos.
- Funções.
- Condicionais (`if` / `else`).
- Laços e métodos de arrays.
- Eventos de clique (`addEventListener`).
- Manipulação do DOM.
- `Math.random()` e `Math.floor()` para sorteios.
- Atualização de elementos HTML com `textContent` e `createElement`.

## 🎯 Objetivo educacional

Estimular o pensamento crítico sobre a relação entre pessoas e inteligência artificial, mostrando que decisões tecnológicas envolvem eficiência, privacidade, segurança, autonomia e responsabilidade coletiva.
